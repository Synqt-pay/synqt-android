# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request. Use GitHub's "Report a vulnerability" button on this repo's Security tab, which opens a private advisory that only SYNQT can see.

Include what you can of:

- the SDK version and the Android version and device you saw it on
- what the problem is and what an attacker could do with it
- steps or code to reproduce it
- any idea you have of a fix

Never include real payer data, card numbers, tokens or merchant keys in a report; use dummy values.

SYNQT acknowledges reports within a few working days, keeps you informed while we fix it, and credits you in the advisory if you want.

## Supported versions

Only the latest 0.x release gets security fixes.
